¿De que Trata esta Práctica?

La práctica consiste en desarrollar un sitio web responsive utilizando exclusivamente HTML, CSS y JavaScript. El objetivo es que los estudiantes aprendan a estructurar correctamente un documento web, aplicar estilos mediante CSS y diseñar interfaces adaptables a distintos dispositivos siguiendo la metodología Mobile First.

El sitio web estará centrado en la publicación de experiencias de viaje. Los usuarios registrados podrán compartir sus vivencias y comentar las publicaciones de otros. En esta segunda fase, el contenido será completamente dinámico.

El proyecto deberá incluir varias páginas HTML: index.html (página principal con una lista de experiencias paginada), login.html (para el inicio de sesión), registro.html (para crear cuentas nuevas), buscar.html (con un buscador de experiencias), experiencia.html (donde se mostrará la información detallada de una experiencia), nueva.html (para la publicación de nuevas experiencias) y acerca.html (con información sobre la práctica y los autores). Todas las páginas compartirán una cabecera con logotipo y barra de navegación, así como un pie de página con información de contacto y derechos de autor.

El diseño debe ser adaptable a diferentes tamaños de pantalla mediante el uso de media queries. Además, se deberá emplear Web Fonts e Icon Fonts para mejorar la apariencia visual. Es obligatorio validar el código HTML en https://validator.w3.org/ y se penalizará el uso de direccionamiento absoluto para archivos externos.

En esta segunda fase se ha dotado a la web de una estructura dinamica compuesta por archivos Javascript que permiten al usuario interactuar con un servidor a traves de llamadas al api y a la base de datos.

Información del Trabajo

Durante la creacion y elaboración de esta practica, mis conocimientos de Javascript han ido evolucionando, ya que he ido aprendiendo en función iba haciendo la práctia. Por ello se pueden observar diferentes metodologias de trabajo en el codigo javascript. Sobretodo lo mas destacable es que al principio hice uso de diferentes archivos js para un mismo archivo html, pero posteriormente descubri que era mejor hacerlo con funciones. Por es el código js de Registro y Login estan en diferentes archivos. CheckLogin.js, CheckPass.js y Registro.js pertecen a Registro.html, y login.js y CompLog.js pertecen a Login.html. También queria comentar que la única parte de la práctica que no he llevado a cabo por dificultades y falta de tiempo a sido la correcta limpieza del formulario de enviar comentarios (0,25p). Por otra parte he hecho algunas incoporaciones adicionales como un boton para mostrar mas comentarios, ya que la página por defecto solo muestra 3, si quieres ver mas tendrás que pulsar sobre ese botón. Para cambiar el nº de Experiencias que se ven en index se ajusta a través de la variable cantidadPaginas.
