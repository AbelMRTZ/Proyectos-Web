1010 COLOR MATCH

¡¡Consigue el mayor numero de grupos de tres o más celdas del mismo color!!

¿De que Trata esta Práctica?

En esta práctica se ha desarrollado una versión simplificada del juego "1010 Color Match", cumpliendo con todos los requisitos establecidos por la asignatura de Programación del Cliente Web del Grado en Ingeniería Multimedia. La aplicación consiste en una cuadrícula de 10x10 celdas donde el jugador debe ir colocando piezas de diferentes formas y colores. El objetivo es formar grupos de tres o más celdas del mismo color para eliminarlas y sumar puntos. El sistema también lleva un recuento del número de piezas colocadas correctamente durante la partida.

La implementación ha sido realizada únicamente con tecnologías vistas durante el curso, es decir, HTML5, CSS3 y JavaScript puro, sin el uso de frameworks externos. Se han utilizado las APIs de HTML para el manejo de eventos y dibujo en canvas, así como para la gestión del almacenamiento temporal a través de sessionStorage. Además, se ha trabajado con fetch para realizar peticiones al servidor RESTful que proporciona las piezas, valida el tablero tras cada movimiento y guarda las puntuaciones.

La estructura del sitio incluye tres páginas principales: index.html, donde se muestra la tabla paginada de puntuaciones; juego.html, que alberga la lógica principal del juego, incluyendo la zona de piezas disponibles y el tablero; y acerca.html, que detalla la autoría del trabajo, problemas encontrados, soluciones aplicadas y otras observaciones relevantes. Se ha seguido la metodología Mobile First para garantizar una correcta visualización en distintos tamaños de pantalla mediante media queries.

Durante el desarrollo, se prestó especial atención a aspectos clave del juego, como el arrastre de piezas sobre el canvas, la comprobación de si una pieza puede colocarse (respetando su forma y sin salirse del tablero), y la eliminación automática de celdas mediante llamadas al servidor. También se ha programado correctamente la detección del fin de partida, que se activa cuando ninguna de las piezas disponibles puede colocarse en ningún lugar del tablero, momento en el cual se muestra un modal al usuario para guardar su puntuación.

En conclusión, esta práctica ha supuesto una integración completa de todos los conocimientos adquiridos durante la asignatura, tanto a nivel de diseño visual como de programación interactiva en el navegador. Se ha logrado una aplicación funcional, dinámica y robusta, con un flujo de juego fluido y una experiencia de usuario adecuada. Además, se ha cumplido con los estándares de validación HTML y CSS exigidos y se han abordado los requisitos de forma modular y clara.
